
# Optimizing Prawn Feed Schedules Based on Real-Time Water pH Data

## Project Overview
This Community Service Project focuses on exploring how real-time water pH monitoring can support better feeding schedule decisions in prawn aquaculture.

## Objectives
- Understand the importance of water pH in prawn farming.
- Study how water quality relates to feeding practices.
- Explore the use of IoT for water quality monitoring.
- Identify opportunities to improve feeding decisions.
